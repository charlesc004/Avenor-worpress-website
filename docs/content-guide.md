# Editing AVENOR

- **Pages → Home:** edit the headline, supporting copy, images, buttons, process, expertise and partnership sections. Move sections with the List View. The AVENOR pattern category supplies reusable editorial sections.
- **Appearance → Editor:** edit Navigation, header, footer, archive introductions and shared templates. Services and Work are native archives, not duplicate pages.
- **Services / Case studies:** add a title, summary, body, optional featured image, and taxonomy. Write capabilities, challenges, solutions, and outcomes using headings and paragraphs. The AVENOR details panel controls featured status and related post IDs. Page order is available under the native page attributes controls.
- **Team / Testimonials:** edit native title, body, excerpt, image, and order. Use AVENOR details for role, company, and optional social profile. Publish only approved people, quotes, roles and affiliations with permission.
- **Collection blocks:** choose a heading, item count, columns, category/industry term ID, and featured or related mode in the block sidebar. Solutions & projects grids also let you select Solution architectures, Delivered projects or All entries. Set the corresponding Entry type in each solution's AVENOR details panel. Existing entries default to architecture guides. The term ID is shown in the taxonomy edit URL. Counts are limited to 12 regardless of supplied attributes.
- **Posts:** publish Insights with native categories, excerpts, featured images, revisions and scheduled publication.
- **Settings → AVENOR business:** change contact details, business profile, social URLs, notification address, CTA label and retention period. An empty social URL is omitted publicly.
- **Inquiries:** use the native list search and workflow-status filter. Open a record to review details and delivery status; select New, In progress, Resolved or Spam and update. Only administrators receive inquiry capabilities by default.
- **Tools → Export/Erase Personal Data:** use WordPress verification to process inquiries associated with an email address.

The seed script creates missing records and preserves matching slugs. Re-running it does not reset page edits. It initializes site settings only once. Imported media are reused by attachment slug. Publish client work and endorsements only when the supporting evidence and permission are available.

The refined homepage also includes Ways to Work Together, Latest Thinking and Useful Questions patterns. FAQs use native Details blocks, so editors can change questions and answers without code. The Insights preview queries native posts automatically. Mobile menu contact information comes from AVENOR business settings, and its links come from the native Navigation block.

Solutions are authored architecture guides with a challenge, implementation approach, delivery scope, operational considerations and acceptance criteria. They do not represent undocumented client engagements. The home page now includes Delivery Standards, Industries and Platform Foundations, all editable as native blocks. No staff profiles, testimonials or inquiry fixtures are created by site initialization.

The Delivered Projects section features AVENOR's own implemented platform, explicitly identified as an in-house project, with a local screenshot of the actual interface. It is separate from the solution architecture collection. About includes four discipline cards and two partnership commitments; these are editorial descriptions, not named staff biographies or attributed client quotes. Team and Testimonials collection blocks automatically show published records; until records are approved and published, they show a contact invitation. Draft profiles and quotes remain private. The one-time section migration preserves existing page content and does not duplicate sections on subsequent initialization.

The owner's subsequent compact-homepage revision keeps the hero, expertise strip, three selected services, one in-house project, two recent articles, FAQs and contact CTA. Detailed discipline and partnership cards remain on About; all six services and architecture guides remain in their archives. Other long-form sections remain available as reusable patterns. `tools/compact-home.php` applies the one-time revision after earlier content upgrades, preserving later editorial edits. Homepage-only spacing and image proportions reduce scrolling without changing inner pages.

The header navigation now runs Contact → Insights → Solutions → Services → About. This is the actual native menu order, so desktop display, keyboard traversal and the mobile drawer agree. The desktop menu uses a rounded dark container and an active-page pill. Change order through the native Navigation editor; the one-time `tools/refine-navigation.php` migration will not override subsequent edits.

Archive and taxonomy grids inherit their batch size from WordPress's main query (Settings → Reading for ordinary archives). This keeps native `/page/N/` routing and collection pagination in agreement. The block's item-count setting controls embedded collections, such as those on Home; it does not override the native archive batch size.
